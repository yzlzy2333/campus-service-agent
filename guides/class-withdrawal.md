# 退学申请咨询

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟教务服务台选择「学籍异动 / 退学咨询」。

与学院学籍窗口确认申请适用情形后，在对应页面填写原因和拟办理日期。提交后查是否需补件及学籍状态何时生效；获批后按通知另办住宿、账单及档案事项。

## 申请入口

在模拟教务服务台选择「学籍异动 / 退学咨询」。

## 办理地点

现场办理或咨询可到学院学籍窗口。在模拟教务服务台选择「学籍异动 / 退学咨询」。
