# 校园安全求助

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟校园安全服务台选择「安全服务 / 值班联络与报告」。

遇到正在发生的危险，先确保自身安全并联系所在地紧急服务。需要校内协助时，通过学校公示的值班渠道说明位置和情况；事后可登记事件。

求助时优先说明校区、楼栋或最近地标、是否有人受伤和是否仍有危险。到安全地点后按现场指挥行动；报告遗失或被盗时补充发现时间和物品特征，保留受理记录。真实紧急情况以所在地正式救援渠道为准。

## 申请入口

在模拟校园安全服务台选择「安全服务 / 值班联络与报告」。

## 办理地点

现场办理或咨询可到学校公示的保卫值班点。在模拟校园安全服务台选择「安全服务 / 值班联络与报告」。
