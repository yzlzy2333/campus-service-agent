# 学生证补办

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟教务服务台选择「学籍服务 / 学生证补办」，下载申请表。

1. 填写学生证补办申请表。
2. 按补办原因备齐材料并交至学籍服务窗口。
3. 审核通过后，凭受理回执到原窗口领取新证。

遗失时备申请表、证件照和遗失说明，损坏时备申请表、证件照和旧证。交件后保存回执；补正原因在原申请看，领取时现场核对姓名与学籍信息。

## 办理地点

到模拟学生事务大厅的学籍服务窗口办理。

## 申请入口

在模拟教务服务台选择「学籍服务 / 学生证补办」，下载申请表。

## 领取地点

审核通过后，凭受理回执到模拟学生事务大厅的学籍服务窗口领取新证。
