# 图书馆电子资源访问

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟图书馆服务台选择「电子资源 / 校外访问」。

从馆藏目录搜索数据库或文献题名，校外通过授权入口验证账号后再进入资源页。打不开时记录数据库名和报错，先核对馆藏授权范围；可向电子资源窗口查询替代获取方式。

## 申请入口

在模拟图书馆服务台选择「电子资源 / 校外访问」。

## 办理地点

现场办理或咨询可到图书馆电子资源咨询窗口。在模拟图书馆服务台选择「电子资源 / 校外访问」。
