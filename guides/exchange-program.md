# 校际交换申请

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟国际交流服务台选择「交流项目 / 交换生报名」。

从项目页核对派出学期、名额、语言与学分要求，准备交换申请表和交流计划。提交后保存申请状态，按通知参加遴选；入选后向学院核对拟修课程与返校学分认定。

## 申请入口

在模拟国际交流服务台选择「交流项目 / 交换生报名」。

## 办理地点

现场办理或咨询可到国际交流服务窗口。在模拟国际交流服务台选择「交流项目 / 交换生报名」。
