# 课表查询

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟教务服务台选择「我的课程 / 学期课表」。

在「学期课表」选学期、周次和日期，核对节次、单双周、校区与教室。查不到某门课时先确认选课状态，再带课程代码和教学班到学院教务窗口核对；调课时看最新课程通知。

## 申请入口

在模拟教务服务台选择「我的课程 / 学期课表」。

## 办理地点

现场办理或咨询可到学院教务窗口。在模拟教务服务台选择「我的课程 / 学期课表」。
