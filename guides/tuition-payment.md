# 学费缴纳

> 模拟资料。用于课程演示与评测。

## 办理流程

1. 登录模拟财务服务台，打开「学生缴费 / 应缴账单」。
2. 在「学年」选择账单所属学年，在「学期」选择「第一学期」（秋季学期），再选择「学费」。缴纳第二学期学费时，在同一筛选项改选「第二学期」。
3. 核对应缴金额和账单状态。仅在账单显示「待缴费」时进入模拟支付。完成后回到原账单，确认状态为「已缴费」并保存订单编号。
4. 若没有待缴账单，先检查学年、学期与项目筛选。如果支付状态仍为「处理中」或已扣款但账单未更新，先在「学生缴费 / 缴费记录」查订单状态；仍有异常时，凭订单编号联系财务服务窗口。

第一学期按「学年 → 第一学期 → 学费」筛选。若账单显示「已缴费」，可从「缴费记录」查订单与支付状态；需要票据时进入「学生缴费 / 电子票据」。

## 申请入口

登录模拟财务服务台，选择「学生缴费 / 应缴账单」。缴第一学期学费时，按「学年 → 第一学期 → 学费」筛选。

## 办理地点

现场咨询可到模拟财务服务大厅的学生缴费窗口。查询订单异常时带上缴费订单编号。

## 办理费用

模拟指南没有统一学费金额，也无法读取个人账单。请在「学生缴费 / 应缴账单」选择学年、学期和「学费」，查看该笔账单的「应缴金额」；住宿费等项目按页面上的独立账单核对。
