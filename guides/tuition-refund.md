# 学杂费退费

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟财务服务台选择「学生缴费 / 退费申请」。

选择需退费的原订单，填写退费说明并提交。经核对后在原申请查看审核状态与退款去向。

先在原缴费记录核对订单编号、付款项目及拟退金额，再填写退费原因并提交。原申请里查看补件、审核和退款去向；显示退回时按原因补正，显示已退时凭原订单核对入账。

## 申请入口

在模拟财务服务台选择「学生缴费 / 退费申请」。

## 办理地点

现场办理或咨询可到财务服务大厅的退费窗口。在模拟财务服务台选择「学生缴费 / 退费申请」。
