# 校园邮箱开通

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟信息服务台选择「账号服务 / 校园邮箱」。

登录服务台查看邮箱地址和状态：已开通可从同页进入 Web 邮箱，未开通则先申请并回查状态。首次登录后用测试邮件验证收发。遇到登录失败可记下报错文字给邮箱支持窗口，勿提供密码或验证码。

## 申请入口

在模拟信息服务台选择「账号服务 / 校园邮箱」。

## 办理地点

现场办理或咨询可到信息服务大厅邮箱支持窗口。在模拟信息服务台选择「账号服务 / 校园邮箱」。
