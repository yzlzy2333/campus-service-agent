# 学生档案转递

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟档案服务台选择「学生档案 / 转递查询」。

先向接收单位核对档案接收名称、地址与接收要求，再填转递登记。发出后在「转递查询」核对寄递单号、签收状态；显示签收但接收方未入库时，先凭单号核对接收记录。

## 申请入口

在模拟档案服务台选择「学生档案 / 转递查询」。

## 办理地点

现场办理或咨询可到学生档案服务窗口。在模拟档案服务台选择「学生档案 / 转递查询」。
