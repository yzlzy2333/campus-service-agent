# 新生学生证办理

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟教务服务台选择「证件服务 / 新生学生证」。

核对姓名和院系，按学院通知提交证件照，由学院集中制作并通知领取。

先从学院通知核对照片规格、提交截止和信息确认方式，再按要求上传证件照。制证完成后到发放点核对姓名与院系并签收；漏领时联系本学院确认补领安排。

## 申请入口

在模拟教务服务台选择「证件服务 / 新生学生证」。

## 办理地点

现场办理或咨询可到学院通知指定的新生证件发放点。在模拟教务服务台选择「证件服务 / 新生学生证」。

## 领取地点

到学院通知指定的新生证件发放点领取。
