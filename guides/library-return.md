# 图书归还

> 模拟资料。用于课程演示与评测。

## 办理流程

在模拟图书馆服务台选择「借阅服务 / 归还记录」。

归还时在还书机确认书目已成功注销，再在个人借阅记录查是否更新。还书机未识别、图书有附件或已逾期时到借阅柜台核对，保留归还回执或记录。

## 申请入口

在模拟图书馆服务台选择「借阅服务 / 归还记录」。

## 办理地点

现场办理或咨询可到图书馆借阅柜台或公告标明的还书机。在模拟图书馆服务台选择「借阅服务 / 归还记录」。
